# Spirit raw point cloud frame encoder
This repository contains the code to build a library that can be used in a Unity application (or any other programming environment that support Dlls) to encode raw frames that have been generated by the [capturer](../point_cloud_capturer/) library.



This library uses the raw color and depth frames produced by capturer and encodes them separately. Color frames are encoded with libjpeg-turbo and depth frames are encoded using run-length encoding. 

## Building
This repository uses CMake to build the library. For Windows you can use the following command to generate the solution
 ```
 cmake -G "Visual Studio 17 2022" -A x64 -S . -B "x64" -DBUILD_SHARED_LIBS=ON -DCMAKE_CONFIGURATION_TYPES=Release
 ```
After this you will to open the generated solution, change the build type to `Release` and press `Ctrl+Shift+B` to build the  Dll.

If you do not have `libjpeg-turbo` library installed you will also need to do the following steps or if you are on Windows use the (easier) alternate method:

* Clone the [Libjpeg-turbo repository](https://github.com/libjpeg-turbo/libjpeg-turbo) 
* Create the CMake files (e.g. `cmake -G "Visual Studio 17 2022" -A x64 -S . -B "x64" -DBUILD_SHARED_LIBS=ON -DCMAKE_CONFIGURATION_TYPES=Release`)
* Make sure to run and build the `INSTALL` project
* If it does not install properly you might have to run `cmake --install . --config Release` (as administrator) in the build directory as well 

Alternatively, for Windows you can also use a [prebuilt library (DLL + header files)](https://cloud.ilabt.imec.be/index.php/s/ErWcyjZa5mk5jyp) and place this in `C:/Program Files/libjpeg`.

## Usage

##### Creates the encoding queue:
This queue holds up to two raw frames (i.e., the frame that is currently encoding and one buffered frame).
```c++
initialize(unsigned int width, unsigned int height, unsigned int jpeg_quality)
```
##### To encode the point cloud from the capturer:
This method is **non-blocking**, and will simply add the frame to the queue. Once the encoder is ready for the next frame it will retrieve it from the queue and encode the depth and color frames. You need to make sure you have called `register_depth_done_callback` and `register_color_done_callback` at the start of your application to receive the depth and color data.
```c++
encode_frame(RawFrame* pc)
```

##### To register the callback that will be used when the color has been encoded:
```c++
register_color_done_callback(ColorDoneCallback cb)
```

This callback has to have the following function definition: 

```c++
func(unsigned char* raw_data_ptr, uint32_t size, uint32_t frame_nr, uint32_t width, uint32_t height, uint32_t n_points,  uint64_t timestamp)
```

##### To register the callback that will be used when the depth has been encoded:
```c++
register_depth_done_callback(ColorDoneCallback cb)
```

This callback has to have the following function definition: 

```c++
func(unsigned char* raw_data_ptr, uint32_t size, uint32_t frame_nr, uint32_t width, uint32_t height, uint32_t n_points,  uint64_t timestamp)
```

##### The encoder will signal when you can free the `RawFrame` by calling a callback function. You can register it with the following function:
```c++
register_free_frame_callback(FreeFrameCallback cb)
```

This callback has to have the following function definition: 

```c++
func(RawFrame* pc)
```

##### To decode the raw data of a color frame:
This method is **blocking**, and will only return once decoding is fully complete.
```c++
DecodedJpeg* decode_color(unsigned char* data, unsigned long size, unsigned int width, unsigned int height)
```

##### To decode the raw data of a depth frame:
This method is **blocking**, and will only return once decoding is fully complete.
```c++
DecodedDepth* decode_depth(unsigned char* data, unsigned int width, unsigned int height)
```

##### Get a pointer to the array containing the decoded RGB values:
```c++
unsigned char* get_decoded_color_data(DecodedJpeg* ptr)
```

##### Get a pointer to the array containing the decoded depth values:
```c++
unsigned short* get_decoded_depth_data(DecodedDepth* ptr)
```

##### To free the decoded color data once you are done with it:
```c++
free_decoded_color(DecodedJpeg* ptr)
```

##### To free the decoded depth data once you are done with it:
```c++
free_decoded_depth(DecodedDepth* ptr)
```

##### To stop the encoder threads after you are done:
```
cleanup()
```
